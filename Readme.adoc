= rubyists/homebrew-tap

Homebrew tap for rubyists CLI tools.

== Install

[source,sh]
----
$ brew tap rubyists/tap
$ brew install linear-cli
----

`linear-cli` installs `lc` (plus the `lcreate`/`lcls`/`lclose`/`lcomment`/
`lproj` wrapper scripts) - the https://github.com/rubyists/linear-cli[linear-cli]
CLI for https://linear.app[Linear.app], covering macOS (Apple Silicon) and
Linux (x86_64).

`sv-helper` installs `sv-helper` (plus the `sv-start`/`sv-stop`/`sv-restart`/
`sv-list`/`svls`/`sv-enable`/`sv-disable`/`sv-find` command links, `rsvlog`
and `runsvdir.sh`) - https://github.com/rubyists/sv-helper[sv-helper]
helpers for administering https://smarden.org/runit/[runit] services,
covering macOS and Linux. Shell scripts, so one archive per OS and no
architecture-specific builds.
